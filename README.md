# API Status

A responsive API status dashboard built with plain HTML, CSS, and JavaScript. All service health, latency, uptime, regional metrics, and incidents are illustrative mock data; the page makes no network requests.

## Run

Open `index.html` in a browser. No dependencies, build step, or server are required.

## Interactions

- Switch the latency chart between 24 hours, 7 days, and 30 days.
- Expand incident rows to read incident updates.
- Refresh the mock status to update the last-checked time.
